QUICK RESTORATION
================================================================================

Prerequisites:
- PostgreSQL service must be running for SQL restore
- Sufficient disk space for decompression
- Database user with restore privileges (typically postgres)

--------------------------------------------------------------------------------
Method 1: Direct Restoration (Recommended)
--------------------------------------------------------------------------------

# Set variables
TIMESTAMP="TIMESTAMP_PLACEHOLDER"
DB_NAME="ecomon"
DB_USER="postgres"
DB_HOST="localhost"
DB_PORT="5432"
BACKUP_DIR="/backup/backup_${TIMESTAMP}"
BACKUP_PREFIX="sql_dump_${TIMESTAMP}"

# Reassemble and extract dump
cat "$BACKUP_DIR"/"$BACKUP_PREFIX".tar.gz.part* | gunzip | tar -xf -

# Restore into database (drops/creates not included in plain SQL by default)
psql -h "$DB_HOST" -p "$DB_PORT" -U "$DB_USER" -d "$DB_NAME" -f "dump_${TIMESTAMP}.sql"

# Optional: remove extracted dump after restore
rm -f "dump_${TIMESTAMP}.sql"

# Restore from chunks
cat "$BACKUP_DIR"/basebackup_${TIMESTAMP}.tar.gz.part* | gunzip | tar -xf - -C "$RESTORE_PATH" --strip-components=1

# Set correct permissions
chown -R postgres:postgres "$RESTORE_PATH"
chmod 700 "$RESTORE_PATH"

# Start PostgreSQL
systemctl start postgresql
# OR for Docker:
# docker start <postgres_container>

Method 3: Verify Before Restoring
--------------------------------------------------------------------------------

# Test integrity without extracting

# Count files in backup

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Permission Denied
Solution: Run with sudo or as postgres user
    sudo -u postgres bash

Issue: Not Enough Space
Solution: Check available space
    df -h /var/lib/postgresql
    du -sh "$BACKUP_DIR"

Issue: Restore Fails with Permission Errors
Solution: Use a superuser or a user with restore privileges
    psql -U postgres ...
