QUICK RESTORATION
================================================================================

Prerequisites:
- PostgreSQL must be stopped before restoration
- Sufficient disk space for decompression
- Root or postgres user access

--------------------------------------------------------------------------------
Method 1: Direct Restoration (Recommended)
--------------------------------------------------------------------------------

# Stop PostgreSQL
systemctl stop postgresql
# OR for Docker:
# docker stop <postgres_container>

# Set variables
TIMESTAMP="TIMESTAMP_PLACEHOLDER"
RESTORE_PATH="/var/lib/postgresql/data"
BACKUP_DIR="/backup/backup_${TIMESTAMP}"

# Backup existing data (safety measure)
if [ -d "$RESTORE_PATH" ]; then
    mv "$RESTORE_PATH" "${RESTORE_PATH}.backup_$(date +%Y%m%d_%H%M%S)"
fi

# Create restore directory
mkdir -p "$RESTORE_PATH"

# Restore from chunks
cat "$BACKUP_DIR"/basebackup_${TIMESTAMP}.tar.gz.part* | gunzip | tar -xf - -C "$RESTORE_PATH" --strip-components=1

# Set correct permissions
chown -R postgres:postgres "$RESTORE_PATH"
chmod 700 "$RESTORE_PATH"

# Start PostgreSQL
systemctl start postgresql
# OR for Docker:
# docker start <postgres_container>

--------------------------------------------------------------------------------
Method 2: Extract to Temporary Location First
--------------------------------------------------------------------------------

# Extract to temporary location for inspection
TEMP_DIR="/tmp/pg_restore_$(date +%s)"
mkdir -p "$TEMP_DIR"

cat "$BACKUP_DIR"/basebackup_TIMESTAMP_PLACEHOLDER.tar.gz.part* | gunzip | tar -xf - -C "$TEMP_DIR"

# Inspect the backup
ls -la "$TEMP_DIR"

# Then copy to PostgreSQL data directory when ready

--------------------------------------------------------------------------------
Method 3: Verify Before Restoring
--------------------------------------------------------------------------------

# Test integrity without extracting
cat "$BACKUP_DIR"/basebackup_TIMESTAMP_PLACEHOLDER.tar.gz.part* | gunzip | tar -t | head -20

# Count files in backup
cat "$BACKUP_DIR"/basebackup_TIMESTAMP_PLACEHOLDER.tar.gz.part* | gunzip | tar -t | wc -l

# Search for specific files
cat "$BACKUP_DIR"/basebackup_TIMESTAMP_PLACEHOLDER.tar.gz.part* | gunzip | tar -t | grep "postgresql.conf"

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Permission Denied
Solution: Run with sudo or as postgres user
    sudo -u postgres bash

Issue: Not Enough Space
Solution: Check available space
    df -h /var/lib/postgresql
    du -sh "$BACKUP_DIR"

Issue: PostgreSQL Won't Start After Restore
Solution: Check PostgreSQL logs
    journalctl -u postgresql -n 50
    # OR for Docker:
    # docker logs <postgres_container>

    # Verify permissions
    ls -la /var/lib/postgresql/data
    # Should be owned by postgres:postgres with 700 permissions
